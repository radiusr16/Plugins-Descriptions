Bots Various Features 0.0.2

Автор: Radius

Описание:

Плагин позволяет гибко настраивать различные аспекты работы ботов.

Особенности:

  • возможность настройки плагина под определенных ботов (см bvf_quota_ref_cvar, bvf_auto_vacate_ref_cvar)
  • возможность гибкой настройки количества ботов в зависимости от онлайна сервера (см bvf_add_quota)
  • возможность назначить ботам случайный ник из файла names.ini
  • возможность назначить ботам случайный SteamID из файла steamids.ini
    Внимание: SteamID отображается только в выводе команды status
  • возможность добавить рекламных ботов в файл исключений exclude.ini
  • все квары и команды для удобства настраиваются в автоматически создаваемом конфигурационном файле 'addons/amxmodx/configs/bots_various_features/bots_various_features.cfg'

Требования:

  • Plugins Core (версии 1.8.0 и выше)
  • ReAPI

Настройки (из автоматически создаваемого конфигурационного файла 'bots_various_features.cfg'):

// bvf_update_config - обновляет файл 'bots_various_features/bots_various_features.cfg' при смене карты // 1 - обновить файл // 2 - сделать бэкап (*.bkp) и обновить файл // Внимание: Текущие значения кваров (кроме команд), запишутся в обновленный файл // Квар со значением прописывается в консоли сервера // После обновления квар сам вернется в значение 0 // Уровень логов // 0 - выключено (OFF) // 1 - предупреждения (WARN) // 2 - информация (INFO) // 3 - отладочная информация (DEBUG) // 4 - подробная отладочная информация (TRACE) // По умолчанию: "2" bvf_log_level "2"
// Название квара, отвечающего за количество ботов // bot_quota - боты встроенные в ReGameDLL // yb_quota - YaPB боты // По умолчанию: "bot_quota" bvf_quota_ref_cvar "bot_quota"
// Название квара, отвечающего за автоотключение бота при подключении игрока // bot_auto_vacate - боты встроенные в ReGameDLL // yb_autovacate - YaPB боты // По умолчанию: "bot_auto_vacate" bvf_auto_vacate_ref_cvar "bot_auto_vacate" // Менять (1) или нет (0) ботам ник из файла names.ini // По умолчанию: "1" bvf_set_name "1" // Назначать (1) или нет (0) ботам SteamID из файла steamids.ini // По умолчанию: "1" bvf_set_steamid "1" // Флаги доступа, отвечающие за видимость BOT у ботов в выводе команды status // По умолчанию: "d" bvf_status_ignore_flags "d"
// bvf_add_quota - консольная команда, добавляющая настройки количества ботов // в зависимости от онлайна сервера // Формат команды: // bvf_add_quota "1" "2" "3" "4" // 1. quota - обязательный аргумент, отвечающий за количество ботов // 2. players_limit - обязательный аргумент, отвечающий за лимит реальных // игроков, при достижении которого с каждым новым игроком один бот будет // выходить с сервера // 0 - значит что с первым игроком, один бот покинет сервер // 3. min_players - обязательный аргумент, отвечающий за минимальное количество // реальных игроков на сервере // 4. max_players - обязательный аргумент, отвечающий за максимальное количество // реальных игроков на сервере bvf_add_quota "20" "0" "0" "32"
